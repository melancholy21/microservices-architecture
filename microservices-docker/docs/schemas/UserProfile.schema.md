# UserProfile Schema Documentation

The **User Service** maintains this schema to handle structural profile configurations, permissions caching (`role`), and UI customization separate from the core login credentials stored in the Authentication Service.

## Schema Definitions

| Field | Type | Required | Unique | Details / Validation |
| :--- | :--- | :---: | :---: | :--- |
| `_id` | ObjectId | System | Yes | Primary Key automatically generated by MongoDB. |
| `authUserId` | String | Yes | Yes | Trimmed cross-service identifier linking this profile explicitly to its parent account entry in the Authentication Service. |
| `role` | String | Yes | No | Cached permission state flag. Enum values: `["client", "staff", "admin"]`. Defaults to `client`. |
| `accountStatus` | String | Yes | No | Lifecycle state tracking flag. Enum values: `["active", "suspended", "unverified"]`. Defaults to `active`. |
| `preferences.theme` | String | Yes | No | UI presentation setting. Enum values: `["light", "dark"]`. Defaults to `dark`. |
| `preferences.language` | String | Yes | No | Internationalization locale code string. Defaults to `en`. |
| `createdAt` | Date | System | No | Timestamp when the profile record was first generated. |
| `updatedAt` | Date | System | No | Timestamp when the profile configuration parameters were last modified. |
