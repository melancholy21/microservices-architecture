# ClientProfile Schema Documentation

The **Client Management Service** manages this schema to track individual client profiles, contact numbers, and corporate alignment tied to a system authentication identity.

## Schema Definitions

| Field | Type | Required | Unique | Details / Validation |
| :--- | :--- | :---: | :---: | :--- |
| `_id` | ObjectId | System | Yes | Primary Key automatically generated by MongoDB. |
| `authUserId` | String | Yes | Yes | Cross-service identifier linking this client profile directly to an account entry in the Authentication Service. |
| `firstName` | String | Yes | No | Trimmed first name of the client contact. |
| `lastName` | String | Yes | No | Trimmed last name of the client contact. |
| `companyName` | String | No | No | Optional trimmed corporate or organizer group title string. Defaults to an empty string. |
| `phoneNumber` | String | No | No | Optional trimmed contact phone or mobile number string. Defaults to an empty string. |
| `status` | String | Yes | No | Profile state tracking flag. Enum values: `["active", "suspended", "pending"]`. Defaults to `active`. |
| `createdAt` | Date | System | No | Timestamp when the profile record was generated. |
| `updatedAt` | Date | System | No | Timestamp when the profile record was last altered. |

## Database Indexing

```javascript
// Optimized for fast identity lookups and clean name searches
clientSchema.index({ authUserId: 1 });
clientSchema.index({ lastName: 1, firstName: 1 });
